# FinHub — обзор

FinHub помогает вести личные финансы: записывать доходы и расходы, следить за бюджетами, ставить цели и смотреть отчёты. Основной интерфейс для ежедневного использования — **Telegram-бот**.

## Что уже работает

### Учёт операций
- Доходы и расходы с категориями. Ненужную категорию можно убрать в архив: она пропадёт из меню, а прошлые суммы останутся в отчётах
- Быстрый ввод текстом: `500 кофe`, `+10000 зарплата`, `50000д кофе`, `1500 руб такси`
- Если валюта в сообщении не указана, бот предлагает валюты из настроек (по умолчанию рубли и донги). Не базовая валюта пересчитывается в базовую по курсу ЦБ на день записи. Отчёты — в базовой валюте, по умолчанию в рублях
- **Голосовой ввод** (opt-in): «запиши расход 300 рублей на продукты» — нужны `VOICE_ENABLED=True` и `OPENAI_API_KEY`
- Редактирование суммы, даты, комментария через inline-кнопки

### Бюджеты
- Месячные лимиты по категориям
- План/факт, остаток, процент выполнения
- Управление из главного меню бота и настроек категорий
- Одно сообщение, когда траты впервые становятся больше лимита

### Цели и конверты
- Цель копится к сумме и показывает процент. Покупка из цели процент не уменьшает: отдельно видно, сколько потрачено и сколько ещё лежит
- Конверт — уже отложенные деньги без процента и без срока. На карточке: сколько лежит, сколько внесено, сколько потрачено
- Пополнение и снятие. Ненужную цель или конверт можно убрать в архив и вернуть. Деньги в архиве остаются в резерве, пока их не снимут
- Любой расход можно списать из выбранной цели или конверта: кнопка «Из цели» на карточке операции
- «Свободно» за месяц — это доход минус расходы минус то, что лежит в целях и конвертах
- Срок цели: при текущем темпе отложений и сколько нужно к дедлайну. Можно спросить: «когда закрою отпуск»

### Отчёты
- Месячные отчёты в боте
- Недельная сводка статьёй с таблицами. Бот проверяет её каждый день в 9:00 по времени Вьетнама и присылает итог прошлой недели один раз. Если в понедельник бот молчал, сводка придёт на следующее утро. Текущую неделю можно открыть командой `/week` или кнопкой «Неделя»
- Excel: операции, кэшфлоу, лист «Цели» с прогрессом, лист «Конверты» (внесено, потрачено, остаток)

### API и админка
- REST API (категории, транзакции, бюджеты)
- Django Admin для управления данными и текстами бота

## Архитектура (кратко)

```
Telegram ←→ Bot (python-telegram-bot)
                ↓
           Django + PostgreSQL
                ↓
           REST API (для будущего фронтенда)
```

Локально и на сервере всё поднимается через **Docker Compose**: web, bot, PostgreSQL, Redis.

## Стек

Python 3.11 · Django 4.2 · PostgreSQL · Redis · Poetry · Docker
