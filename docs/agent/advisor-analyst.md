## Где лежит промпт

`telegram_bot/prompts/advisor_analyst.txt`. Не строка в базе: текст называет поля снимка и форму JSON, поэтому меняется вместе с кодом. Кнопка «Финансист» и фраза ожидания — строки меню, не `BotText`. Старый `advisor_answer.txt` удалён.

## Поведение

Кнопка **«Финансист»** на всю ширину под рядами главного меню. Нажатие на 5 минут ждёт один вопрос, голосом или текстом, и пишет об этом. Режим снимается ответом, другим нажатием, «Назад», `/start` и главным меню.

Пока режим включён, сообщение не идёт в парсер операций. Голос только расшифровывается. Сообщение, которое начинается с суммы, операцию не создаёт: бот просит отправить его обычным сообщением.

Короткие узнаваемые вопросы («сколько потратил», «когда закрою») по-прежнему идут в консультанта без кнопки. Оба входа получают одну статью.

Абзацы берёт JSON модели (`fact` / `advice` / `clarify` / `decline`). Таблицы считает Python из снимка. Пустую таблицу не шлёт. Кривой JSON не показывается: одна повторная попытка, затем короткая фраза. Под статьёй — «Ещё вопрос» и «Главное меню». Если статья не принимается, уходит обычный HTML.

Модель — `VOICE_LLM_MODEL`, по умолчанию `gpt-4o-mini`, до 900 токенов, низкая температура, по возможности объектный JSON.

В снимке есть открытые долги (остаток и направление, без ставки) и до восьми ближайших активных повторов.
